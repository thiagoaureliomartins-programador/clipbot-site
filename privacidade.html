Política de Privacidade

Última atualização: 26 de outubro de 2026

Dados que o ClipBot recebe do TikTok

  • Informações básicas do perfil (identificador, nome de exibição e avatar), para mostrar qual conta está conectada.
  • Token de acesso, usado apenas para enviar os vídeos que o usuário escolheu publicar.

Onde ficam os dados

O ClipBot roda no computador do próprio usuário. Os vídeos, as transcrições e o token de acesso ficam salvos localmente nessa máquina e não são enviados a servidores do ClipBot.

Serviços usados

Os vídeos editados são enviados ao TikTok pela API oficial. A transcrição do áudio é feita localmente; o texto transcrito pode ser enviado a um serviço de IA apenas para escolher os melhores trechos.

Compartilhamento

O ClipBot não vende nem compartilha dados pessoais com terceiros.

Remoção

Para apagar os dados, basta revogar o acesso nas configurações do TikTok e excluir a pasta do ClipBot no computador. Dúvidas podem ser enviadas pela página de issues do repositório do projeto no GitHub.
